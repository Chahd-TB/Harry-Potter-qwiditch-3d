# 🧹 Harry Potter Quidditch Playground 3D Model

A full 3D model of the Quidditch playground from Harry Potter, created in Blender.
The project includes the entire pitch, hoops, stands, and environment, capturing the magical sport’s iconic setting in 3D.

# 🖥️ Overview

The project features:

Complete Quidditch pitch with marked playing field

Goal hoops and stands for players and spectators

Surrounding environment like stadium structure and seating

Practice in large-scale 3D scene modeling and layout composition

# ⚙️ Tools Used

Blender
